## Core Verbs (12)

## Patterned Irregulars (26, six sub-groups)
- Stem-changing o→ue (4): dormir (sleep), encontrar (find), jugar (play — games), recordar (remember)
- Stem-changing e→ie (5): cerrar (close), entender (understand), pensar (think), perder (lose), sentir (feel)
- Stem-changing e→i (3): servir (serve), pedir (ask for / request), conseguir (get / achieve)
- Spelling change (4): buscar (search / look for), llegar (arrive), pagar (pay), sacar (take out / extract)
- -go verbs (5): mantener (maintain), poner (put / place), salir (leave / go out), traer (bring), venir (come)
- Regular -er/-ir (5): correr (run), deber (should / must / owe), permitir (allow), recibir (receive), subir (go up / climb)

## True Irregulars (9)
